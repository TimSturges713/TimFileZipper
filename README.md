# TimFileZipper (V1)
Mini project, just a practice with using algorithms to get more familiar. This one is a compression algortihm.

Can decompress and compress .txt and .tim files using the LZ77 algorithm with prefix hash table for quicker compression.

LZ77 algorithm complete, uses a command line interface. Just follow the guidelines it lays out for you.

Next step is to experiment with an .msi installer that users will have in their Windows right-click menu. Just a way to dip my toes in some Windows tinkering.
